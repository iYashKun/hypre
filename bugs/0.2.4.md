# Bug Fixes for 0.2.4

## Fixed

- **Windows npm-script execution:** `hypre run <script>` selected `npm.cmd` on Windows, but child processes were always started with `shell: false`. Windows command scripts require a shell, so npm-script launches failed before the selected script could run. Runner definitions can now opt into shell execution, enabled only for the Windows npm runner; other runners remain shell free.

## Verification

- `npm run build` passes.
- A focused platform selection check confirms Windows uses `npm.cmd` with shell execution and non-Windows runners stay shell free.
- The scheduled restart failure path was exercised and did not produce an unhandled rejection; no change was needed there.
